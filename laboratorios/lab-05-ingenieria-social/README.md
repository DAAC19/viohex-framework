# FC-LAB-005. Construcción y análisis de escenarios de ingeniería social

| Campo | Descripción / dato requerido |
| --- | --- |
| Identificador | FC-LAB-005 |
| Nombre y versión | Construcción y análisis de escenarios de ingeniería social. v1.0, 06/10/2026. |
| Objetivo | Reconocer los elementos de un ataque de ingeniería social y proponer medidas preventivas mediante una matriz de análisis. |
| Dominio y fase | D05 Factor humano. Fases 02 Prevención y 04 Análisis. |
| Roles | Diseñador del escenario y analista: Diego Alberto. Revisor: el autor del escenario recibido, cuya matriz sirvió de comparación. |
| Entorno y autorización | Ejercicio de papel. Los escenarios son hipotéticos y no se desplegaron contra personas reales; no se recolectaron credenciales. |
| Entradas | Plantilla de la matriz de análisis (contexto, objetivo, canal, pretexto, identidad, persuasión, acción, clasificación, técnicas, indicadores y medida preventiva) y el escenario recibido de un compañero. |
| Procedimiento | 1. Construir un escenario propio: quishing con un póster que promete un premio secreto de Bienestar Universitario durante la Semana Tomasina. 2. Analizar el escenario recibido (correo de supuesto soporte técnico por actividad inusual) respondiendo las preguntas guía. 3. Completar la matriz con identificación y justificación. 4. Comparar la matriz propia con la del autor. 5. Concluir. |
| Evidencias | Matriz del escenario propio, matriz justificada del escenario recibido y comparación con la del autor. |
| Criterio de aceptación | El análisis clasifica correctamente la técnica del escenario recibido (phishing con suplantación) y coincide con la matriz del autor en los elementos principales. |
| Análisis defensivo | Indicadores: dominio o enlace desconocido y urgencia artificial. Medidas: verificar el remitente y la información por los canales oficiales, no abrir enlaces dudosos, reportar el correo, cambiar las credenciales y activar MFA. |
| Resultado | Escenario de quishing documentado y análisis del phishing recibido coincidente con el del autor; la única diferencia está en el contexto, que el escenario no especifica. |
